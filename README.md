### I have faced few challenges while completing this assignment as I'm new to react. One key difficulty is managing complex state across multiple components, especially when implementing features like filtering, sorting, and favorites using React Context API. Handling routing between list and detailed views smoothly can also be tricky, particularly when dealing with dynamic parameters and ensuring the app doesn't break on refresh. Performance optimization using useMemo and useCallback may be confusing for those unfamiliar with React internals. Building a comparison tool and implementing persistent favorites using localStorage adds additional layers of logic that require careful planning. Lastly, deploying the app and ensuring all features work reliably across environments may be a new and demanding experience for some.

### A brief Explanation on my approach in making this project
1. Handled Complex Nested Pokémon API Data:
Successfully managed deeply nested data structures, especially within the base_state, which required careful extraction and rendering of multiple state layers from the API response.


2. Managed Multiple States and Pagination:
Implemented efficient state management strategies to handle various application states, including user interactions and paginated data fetching for seamless browsing.


3. Implemented Shimmer UI for Loading States:
Integrated a shimmer (skeleton) UI to enhance user experience during data fetches by displaying placeholders while content is loading.


4. Implemented Robust Error Handling:
Ensured application stability and user feedback by gracefully handling API errors and displaying appropriate error messages or fallback UI.
